# Prospex Frontend

Next.js 16 + React 19 + TypeScript + Tailwind CSS v4 client for the Prospex
Lead Discovery & Qualification Platform.

Full setup and architecture documentation lives in the repository
[`README.md`](../README.md).

## Quick start

```bash
npm install
npm run dev        # http://localhost:3000
```

The app expects the backend at `http://localhost:8000` (override with
`NEXT_PUBLIC_API_URL`).
